Accessibility Statement

PV Junk is committed to making our website accessible to everyone, including people with disabilities.

Our commitment

We believe everyone should be able to learn about and book our services without barriers — regardless of how they use the web. We've designed pvjunk.com to work with screen readers, keyboard navigation, and assistive technologies, and we test against industry standards to make sure that's actually true in practice.

Standards we follow

This site aims to conform to Web Content Accessibility Guidelines (WCAG) 2.1 Level AA, the international standard for digital accessibility published by the World Wide Web Consortium (W3C). WCAG 2.1 AA is also the standard referenced by the Americans with Disabilities Act (ADA) for web content.

What we've done

Specific measures we've taken to support accessibility include:

  • Color contrast: All text meets a minimum 4.5:1 contrast ratio against its background (3:1 for large text), so it's readable for users with low vision.
  • Keyboard navigation: Every interactive element — links, buttons, the contact form, the Instant Quote tool — can be reached and operated using only a keyboard.
  • Visible focus indicators: A clear amber outline appears around whichever element is keyboard-focused, so users always know where they are on the page.
  • Skip-to-content link: Keyboard users can skip past the navigation directly to the page content.
  • Semantic structure: Headings, landmarks (header, main, footer, nav), and ARIA labels help screen reader users understand and navigate the page.
  • Form accessibility: Form fields have visible labels properly associated with their inputs, and status messages are announced to screen readers.
  • Modal focus management: When the contact form opens, keyboard focus is trapped inside so users don't get lost.
  • Reduced motion support: Users who set "reduce motion" in their operating system get a still page with no decorative animations.

How we test

We use axe-core, an industry-standard automated accessibility testing tool, to audit the site against WCAG 2.1 AA criteria. The site currently passes all applicable automated checks. We also test manually with keyboard navigation.

Known limitations

Even with thorough testing, no site is perfectly accessible to everyone. Some areas where we know improvements are still possible:

  • Some third-party embedded content (Google reCAPTCHA, for example) is governed by Google's own accessibility implementation, which is generally good but outside our direct control.
  • Automated testing can't catch every issue. We rely on user feedback to identify problems we may have missed.
